## 💡 QUICK TIPS

```
Tip 1: Always activate venv before working
$ source venv/bin/activate

Tip 2: Run server with loglevel
$ python manage.py runserver --debug=false

Tip 3: Create demo data in shell
$ python manage.py shell
>>> from students.models import Student

Tip 4: Check database
$ python manage.py shell
>>> from students.models import Student
>>> Student.objects.all()

Tip 5: View migrations
$ python manage.py showmigrations

Tip 6: Test API with curl
$ curl http://127.0.0.1:8000/api/students/

Tip 7: Collect static files (production)
$ python manage.py collectstatic --noinput

Tip 8: Backup database
$ cp db.sqlite3 db.sqlite3.backup
```

## 📞 TROUBLESHOOTING

| Issue | Solution |
|-------|----------|
| Port 8000 in use | `python manage.py runserver 8001` |
| venv not found | Create new: `python3 -m venv venv` |
| Database locked | Remove `db.sqlite3` and migrate again |
| Import errors | Ensure venv is activated |
| Admin not working | Create superuser: `python manage.py createsuperuser` |
